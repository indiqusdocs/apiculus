# About this Release
This is a major release that brings a set of enhancements focused on improving the flexibility and performance of the Apiculus platform. These updates aim to strengthen the overall system and deliver a more secure and reliable experience for users.

 ## New Features
- Proforma Invoice management
- Wallet support for Proforma Invoice payments
- Proforma Invoice tax deduction support
- Email notifications for Proforma Invoice
### Proforma Invoice Management 
A new Proforma Invoice module has been introduced to support advance payment 
requests. 
Key features: 
- Generate Proforma Invoices at both Global and Account levels. 
- Create line-item based Proforma Invoices with automatic subtotal, tax and grand total calculations.
- Download, search, filter, resend and cancel Proforma Invoices. 
- Record payments directly against Proforma Invoices through the Add Transaction flow. 
This provides a structured mechanism for requesting, tracking, and reconciling advance 
payments. 

Subscribers can now access a dedicated Proforma Invoices section under Billing. 

Key features: 
• Dedicated Proforma Invoices tab. 
• View invoice details and payment status. 
• Download Proforma Invoices. 
• Pay individual Proforma Invoices using the Pay Now action. 

This improves visibility into upcoming payment obligations. 
## Proforma invoice payments using Wallet  
The Wallet and Transactions flow now supports payments against Proforma Invoices.  

Key features:  
- Separate tabs for Invoice and Proforma Invoice payments. 
- Payment distribution across multiple Proforma Invoices.  
- Automatic creation of transaction records.  
- Excess payments continue to be credited to Advance Balance.  
- This gives subscribers greater flexibility while making advance payments.
## Tax deduction support for Proforma Invoices  
Tax deduction workflows have been extended to support Proforma Invoices.  

Key Features:  
- Dedicated Proforma Invoice tab in Tax Deduction.  
- Bulk upload templates for PI tax deductions.
-  Account-level PI tax deduction management.  
- Support for fiscal year and quarter-based reconciliation.
## Email notifications for Proforma invoices  
Email notifications are automatically sent whenever a Proforma Invoice is generated.  

The notification includes: 
- Proforma Invoice Number  
- Amount Payable  
- Due Date  
- Description  
- Link to access the Proforma Invoice from the Account Centre.
## Enhancements
- Instance Operation Controls
- ACL Management Enhancements
- VPC Network Validation Improvements
- Encrypted Infrastructure Offerings
- Secondary IP Support for VPC Networking
- Internal Load Balancer (ILB)
- Virtual Router Management
## Instance Operation Controls  
Administrative controls have been enhanced to allow lifecycle operations on compute instances and storage volumes to be centrally governed at the subscription level.  

Key Enhancements: 

- Added subscription-level controls to enable or disable instance and volume lifecycle operations.  
- Restricted operations are consistently enforced across both the user interface and backend services.  
- Lifecycle actions such as start, stop, restart, reconfiguration, networking, restore points and storage operations are automatically controlled based on subscription policy.  
- Provides stronger governance during maintenance windows, compliance events and operational restrictions.  
- This enhancement gives administrators centralized control over infrastructure operations while ensuring policy enforcement across the platform.
## ACL Management Enhancements  
Firewall Access Control List (ACL) management has been enhanced with enterprise-scale bulk administration capabilities.  

Key Enhancements: 
- Added support for importing ACL rules using spreadsheet templates.  
- Introduced ACL export functionality for backup and offline review.  
- Added bulk deletion of multiple ACL rules.  
- Enhanced validation, background processing, and activity logging for bulk operations.
- This significantly reduces administrative effort and improves operational efficiency when managing large firewall rule sets.
## VPC Network Validation Improvements  
Virtual Private Cloud provisioning has been enhanced with stricter network validation and subnet controls.  

Key Enhancements:  
- Restricted VPC creation to support private network ranges.  
- Improved subnet mask validation during VPC creation.  
- Added validation to prevent overlapping CIDR ranges.  
- Enhanced user guidance during network configuration.  
- These improvements help prevent networking conflicts while promoting efficient IP address utilization.  
## Encrypted Infrastructure Offerings  
Compute and storage offerings now support both encrypted and non-encrypted deployment options.  

Key Enhancements:  
- Added encrypted variants for compute and disk offerings.  
- Restricted unsupported storage operations for encrypted workloads.  
- Added contextual messaging to explain unavailable functionality.  
- Enhanced backend validation to consistently enforce encryption policies.  
- This enhancement improves workload security while providing a predictable user experience.

## Secondary IP Support for VPC Networking  
VPC networking now supports assigning multiple secondary IP addresses to compute instances.  

Key Enhancements: 
- Added support for acquiring secondary IP addresses.  
- Secondary IPs can be used with Static NAT, Load Balancer, and Port Forwarding configurations.  
- Added support for default network tier selection.  
- Enhanced validation for IP ownership and network configuration.  
This provides greater flexibility for hosting multiple services and advanced networking scenarios.

## Internal Load Balancer  
Internal Load Balancer (ILB) capabilities have been introduced to support traffic distribution across private workloads within a Virtual Private Cloud.  

Key Enhancements:  

- Added dedicated Internal Load Balancer rule management.  
- Support for tier-based backend instance configuration.  
- Added instance attachment and removal workflows.  
- Introduced validation for duplicate rules, port conflicts and instance eligibility.  
- Automatically maintains backend associations during infrastructure lifecycle events.  
This enhancement improves application availability and enables secure internal service communication.  

## Virtual Router Management  
Virtual Router visibility and lifecycle management have been introduced for VPC networking.  

Key Enhancements:  

- Added a dedicated Virtual Router section within VPC details.  
- Displays router status, IP address, and redundancy information.  
- Supports router start, stop and restart operations.  
- Provides improved operational visibility into VPC gateway infrastructure.  
This enhancement simplifies network administration while providing better insight into virtual networking components.

## Bug fixes  

- Improved the Account Impersonation UI by fixing the disappearing "Confirm" button on the hover.  
- Improved Credit Note upload reliability by fixing the file import failure for XLSX templates.  
- Resolved an issue preventing VFI configuration price updates from being saved in Admin Default Services.  
- Fixed the Account Data Export feature by ensuring the downloaded ZIP contains the correct account information.  
- Improved the Restricted Domains page by restoring search functionality for the Free Email Providers list.
