# Version 2.6.3.0
```
Date: 6.10.2026
Type: Major
```

# About this Release
This release includes enhancements to the admin and subscriber portals for Proforma Invoice (PI) creation and management, payment processing, and tax deduction workflows.

**Enhancements** 

To simplify Proforma Invoice creation and the tax deduction workflow, the following changes have been introduced:
- **PI notifications:** Email notifications will not be triggered when a PI attachment is added for the first time. The **Resend** button has been replaced with **Send** for subsequent email delivery. 
- **Product family and HSN codes**: During PI generation, Product Family in the line-item entry is now available as a dropdown. The corresponding HSN codes are displayed based on the selected product.
- **Customer selection**: Admin accounts are no longer displayed in the customer list while creating a Proforma Invoice, ensuring that only relevant customer accounts are available for selection. 
- **Tax Deduction labels**: Distribution labels displayed while adding tax deductions for Invoices have been aligned with the labels used for Proforma Invoices, providing a consistent experience across both workflows.


To improve the subscriber experience, clear and informative messages are now displayed in the following cases:
- **Proforma Invoice Payment:** A clear message is displayed when no eligible Proforma Invoices are available for payment.
- **Empty State Messaging:** Clear messages are displayed when no open records are available for Invoices or Proforma Invoices.
